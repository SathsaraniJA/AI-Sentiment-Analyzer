# AI-Sentiment-Analyzer
A beginner-friendly Python project that detects Positive, Neutral, or Negative text using Hugging Face NLP models.

## How to Run
1. Install required libraries:
2. Open `sentiment_analyzer.ipynb` in Google Colab or Jupyter Notebook
3. Run the notebook and enter text to analyze sentiment

## Examples
- Input: "I love AI!" → Sentiment: POSITIVE 😊
- Input: "It’s okay, not great." → Sentiment: NEUTRAL 😐
- Input: "I hate waiting!" → Sentiment: NEGATIVE 😡
